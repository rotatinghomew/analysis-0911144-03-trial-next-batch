# 业务资料口径

fractions 的键为声明的全部组分，非负且合计 total_fraction；每次试验成本为组分比例与 costs 内成本的点积。max_cost 是建议批次的总预算上限，不代表已经安排的试验。strength 越大越好，loss 越小越好，不能推断两者固定换算率。visible_at 是试验记录对规划者可见的整数时点；pending 不具有结果，failed 只证明该组合失败而非强度为零。batch 代表共同炉次。下一批的数量、制造可行规则和性能底线是请求参数，预测的可行性不等于安全认证。

小样本用于手工核对字段和边界；历史样本只扩展观测量，不保证任何推断、优化或方案一定成立。实际分析应允许信息不足或条件冲突。
